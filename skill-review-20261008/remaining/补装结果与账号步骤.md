## 需要本人操作：按需选服务，不必全部注册

### 1. inference.sh（ai-video-generation 使用）

1. 打开 Windows PowerShell。
2. 执行：`& "D:/Codex/video-runtime/node_modules/.bin/belt.cmd" login`。
3. 打开命令输出的官方登录网址，在浏览器注册或登录并授权。
4. 如果终端没有自动完成、网页给出 claim code，在你自己的终端执行 `& "D:/Codex/video-runtime/node_modules/.bin/belt.cmd" login --code "网页给你的代码"`。不要把代码发到聊天。
5. 完成后只回复“inference.sh 已登录”，再由助手执行不生成媒体的连通性验证。生成前另查价格和余额，不自动充值。

### 2. fal.ai（genmedia、cinematography、storytelling 的模型调用）

1. 打开 https://fal.ai/dashboard/keys 并登录。若跳转，使用控制台的 API Keys 页面。
2. 创建供模型调用的 API Key，选界面提供的最小必要权限。保存到自己的密码管理器。
3. 在 Windows PowerShell 执行下面的隐藏输入命令，将密钥放在本机用户环境变量；变量以本机明文环境设置保存，不适合共享 Windows 账号。

```powershell
$falSecret = Read-Host "粘贴 FAL_KEY（输入隐藏）" -AsSecureString
$falPlain = [System.Net.NetworkCredential]::new("", $falSecret).Password
[Environment]::SetEnvironmentVariable("FAL_KEY", $falPlain, "User")
$env:FAL_KEY = $falPlain
Remove-Variable falPlain, falSecret
```

4. 重新打开 Codex 让它继承变量，只回复“fal 已配置”，不要发密钥。之后由助手验证模型查询；不自动提交收费生成任务。

### 3. HeyGen（数字人或其云端素材）

1. PowerShell 执行 `& "D:/Codex/video-runtime/bin/heygen.exe" auth login --oauth`。
2. 在打开的 HeyGen 官方网页完成登录授权。
3. 回到终端看到成功后，只回复“HeyGen 已登录”。API 和订阅额度可能不同，以账号显示为准。

### 4. ElevenLabs（可选，本地配音已可用）

1. 登录 https://elevenlabs.io ，进入 Developers / API Keys 创建密钥；界面名称可能变化。
2. 在 PowerShell 用以下命令隐藏输入保存。

```powershell
$voiceSecret = Read-Host "粘贴 ELEVENLABS_API_KEY（输入隐藏）" -AsSecureString
$voicePlain = [System.Net.NetworkCredential]::new("", $voiceSecret).Password
[Environment]::SetEnvironmentVariable("ELEVENLABS_API_KEY", $voicePlain, "User")
Remove-Variable voicePlain, voiceSecret
```

3. 重开 Codex，只回复“ElevenLabs 已配置”。不要把密钥发聊天；用户环境变量同样是本机明文配置。

本地模板渲染和已配置的配音/转写无需以上云账号。云服务登录、充值、付费生成均未执行。
