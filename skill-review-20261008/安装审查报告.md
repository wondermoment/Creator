## 安全与失败记录

- scientific-visualization：首次整仓下载长时间未完成，主动终止；按安装器支持的 Git 方式重试，最终返回 `Host key verification failed`。安装器内部先尝试 HTTPS，再回退 SSH；最终错误不能证明初次 HTTPS 的具体失败原因。按用户要求停止该项，未安装。
- 解决方向：通过可信渠道核对 GitHub SSH 主机指纹并修复本机 SSH 配置，或在后续明确处理该项时恢复正常 HTTPS 下载；不要关闭 StrictHostKeyChecking、TLS 验证或安全扫描。本轮未修改这些设置。
- 此前“未通过安全扫描”的原始日志不可用；无法把旧扫描结论归因于某条脚本，当前安装过程中未收到该项扫描报告。
- 扩展文件下载出现 20 次 TLS unexpected EOF（连接中断，不是证书验证失败）；保持 TLS 校验、降低并发后重新下载全部成功。
- media-use 的官方遥测代码可能向 PostHog 发送账号邮箱/用户名及粗粒度用量事件；已设置用户环境变量 HYPERFRAMES_NO_TELEMETRY=1。新启动进程继承；当前已打开的应用可能需要重启。未执行该工具的遥测调用。
- ElevenLabs 文档包含远程安装脚本管道示例，未执行。Skill 安装本身只是复制说明和资源。
- genmedia 名称对应多个不同第三方项目，未确认唯一来源，因此没有随机选一个安装；本轮用已确认来源的 media-use 和已有 muapi-media-generation 覆盖相关素材功能。

3. 口播素材再加工：已有 video-use/videocut + talking-head-recut + speech-to-text + voice-isolator。
4. 品牌包装：motion-graphics + animate-text + hyperframes-animation + 已有 cover、guizang-social-card-skill。
5. 数字人/生成镜头：已有 heygen-video、heygen-avatar、muapi-media-generation、muapi-seedance-2；账号和成本在实际生产前配置。
6. 产品宣传与音画节奏：product-launch-video + slideshow + music-to-video + music/sound-effects。
