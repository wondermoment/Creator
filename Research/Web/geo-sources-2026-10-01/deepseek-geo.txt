## 什么是 GEO？GEO 和 SEO 有什么区别？

**GEO（Generative Engine Optimization，生成式引擎优化）** 是品牌在 AI 搜索时代必须掌握的新能力。

| 维度 | 传统 SEO | GEO（生成式引擎优化） |
|------|---------|-------------------|
| 目标引擎 | Google、百度 | DeepSeek、豆包、Kimi、文心一言、通义千问 |
| 优化目标 | 关键词排名、点击率 | AI 回答中的品牌提及率、情感倾向 |
| 内容形式 | 网页、外链 | 结构化知识、权威内容、多平台分发 |
| 效果验证 | 排名变化 | AI 推荐频次、品牌曝光率 |

> **一句话理解 GEO**：让 AI 在回答用户问题时，主动提到并正面描述你的品牌。

## 核心功能

### 🔍 AI 搜索品牌监控（GEO 评估引擎）
实时追踪品牌在 DeepSeek、豆包、Kimi、文心一言、通义千问、元宝等主流 AI 搜索引擎中的出现情况：
- 品牌提及率、排名位置、情感倾向
- 跨平台横向对比，生成综合 GEO 健康度评分
- 历史趋势追踪，量化优化效果

### 🚨 违规 GEO 合规检测
帮助品牌规避 AI 投毒（黑帽 GEO）风险，识别并预警：
- 过度关键词堆砌、虚假引用注入
- 竞品恶意操控 AI 推荐内容
- 不符合平台规范的灰帽 GEO 手段

> 315 后合规 GEO 是必答题，超算GEO 内置三层合规检测架构。

### 📝 GEO 内容生成
AI 辅助生成符合各平台规范的 GEO 优化内容，提升品牌在 AI 回答中的自然权重：
- 结构化品牌知识库管理
- 针对不同 AI 引擎的内容策略差异化生成

### 📤 全渠道内容分发（2万+ 媒体渠道）
一键将优化内容发布至知乎、微博、今日头条、小红书、百家号等自媒体平台，
构建多平台内容矩阵，扩大 AI 训练数据覆盖面。

### 📊 GEO 数据看板
- 各 AI 平台品牌曝光趋势图
- 关键词覆盖率、竞品对比分析
- GEO 优化 ROI 量化报告

## 快速开始

### 环境要求

- Node.js >= 14

### 安装与配置

```bash
git clone https://github.com/DeepSeekGEO/deepseek-geo.git
cd deepseek-geo

npm install

cp .env.example .env.local
# 编辑 .env.local，填写后端 API 地址
```

### 开发 / 构建

```bash
npm run dev      # 开发模式，默认 localhost:9527
npm run build    # 生产构建，输出至 dist/
```

详细配置项见 [`.env.example`](.env.example)。
