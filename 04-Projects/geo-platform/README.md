# 品牌铸匠 GEO · 本机企业内容交付平台

最新实现与验收见 [ITERATION-34.md](ITERATION-34.md)，历史入口见 [ITERATION-02.md](ITERATION-02.md)。当前为本机开发版，尚未部署公网。

## 打开与保存

在项目目录运行 `./start.ps1`，访问 `http://127.0.0.1:8787`。依赖 Python 3.12 与 requirements.txt。数据保存在 `.runtime/geo.db`，企业上传素材在 `.runtime/assets/<企业ID>/`；备份应保留整个 `.runtime`，不提交其中密钥、会话和客户数据。

## 当前使用流程

1. 企业资料：维护品牌档案、知识事实、问答和图库，事实经核准后供创作使用。
2. 爆款复刻：粘贴参考文章或视频字幕，拆解框架、开篇、价值表达、结尾等方法，选择标题、开篇、框架等模块沉淀到企业内容资产库，独立编辑并组合复用。
3. 内容专家：选择独立专家对话，包括策略胡老师、内容、技术、SEO/GEO、视频脚本及审校；历史持久化，同一用户跨专家需求按相关性检索。核心 Soul/提示词仅技术管理员可管理。
4. 一鱼多吃：选择已有原稿，生成长文、小红书、小绿书、朋友圈、社群、私聊、口播、直播等文案，分别保存草稿。脚本不是已生成视频。
5. 内容工作流：完善原稿及配图排版，在工作台/排期顶部预览审核。已有客户稿可导出单张长图与离线 HTML。
6. 矩阵发布：审批绑定版本，显式安排渠道任务，保留真实/人工回执。页面跳转不会自动发布。
7. 网站 SEO：单页实际抓取、八项静态检查、问题处理记录、复测验证。GEO 诊断单独保存人工平台回答并分析证据。

动态监控大屏独立置顶；算力积分和充值位于侧栏底部，仅展示已记录用量，余额/支付待接入。

## 已实现与边界

- 企业成员权限、版本审计、知识失效传递、预览审批门禁、异步任务与失败记录已实现。专家上下文有长度和相关性上限，不承诺无限记忆。
- 本机已授权企业可使用当前 Codex 登录的真实模型通道，也支持企业 OpenAI 兼容 API。主管侧栏与自动排期仍含本地规则/模板流程，不能等同于全部接入模型。
- PDF 基础解析与独立 Docling/Crawl4AI 环境已有测试；WordPress 文本草稿/发布及 OpenGEO 汇总有适配器与模拟协议测试，客户外部端到端验收待完成。带图文稿目前以导出包/长图人工交付为主。
- 爆款链接只存出处；视频下载、转录、AI 成片及自动 App 采样未接入。没有证据不生成排名或传播效果承诺。
- 短信找回、正式积分账本/充值支付、公网 HTML 分享、全站 SEO 和站长数据待接入。正式部署前验收 HTTPS、账号归属、备份恢复与访问审计。
- 本机调度需要服务进程运行；关机或服务停止期间不运行。Codex 持续迭代也依赖应用及执行环境可用。

## 验证

后端：`python -m unittest discover -p 'test_*.py' -v`，使用临时数据库。前端：`node test_frontend.cjs`、`node test_review_workspace.cjs`、`node test_workspace_ui.cjs`、`node test_proof_frontend.cjs`、`node test_publish_handoff.cjs`、`node test_auth_frontend.cjs`。实测与模拟分别记录在最新验收文档。
