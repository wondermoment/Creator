# HQHF公开文章研究交付

完成日期：2026-10-05（北京时间）。只读取公开网页，未接触客户数据库、账号凭证或已确认公众号草稿。

## 结果

- 726个可达公开HTML页面；483个文章型详情页；最终抓取错误0、剩余队列0。
- 445条来自新闻7栏目，38条来自其他公开链接。
- 771,508正文字符，含部分英文；25篇无HTML正文，30篇不足100字符，图片URL已留存，未OCR。
- 474组规范化正文或图片集合。去重只是语料组织，同文本或空白不代表业务上同一篇，所有483个来源仍保留。
- 已遍历公开同域链接图，不宣称覆盖未链接历史页、私有内容、附件或图片内全部文字。

## 使用入口

- `SKILL.md`：共享简报、论证结构、角色路由、八形式引用及事实审核。
- `references/expert-roles.md`：六角色分工。
- `references/`其余8个Markdown：独立内容形式规范，带版本，支持仅选中生成与单稿修改。
- `METHODOLOGY.md`：代表原文证据、可借鉴结构、不能迁移的事实、建议验收用例。
- `coverage.json`：最终抓取覆盖/错误/链接图收敛记录。
- `category-coverage.json`：七栏目明细和URL列表。
- `inventory.json`：全部页面概览。
- `article-method-inventory.csv`：483篇的标题、分类、关键词结构信号、图片数。
- `corpus-statistics.json`：文本量及规则分类统计。
- `deduplicated-corpus.json`：规范化语料分组，保留代表与别名来源。
- `articles/*.json`：来源、标题、元数据、正文、段落、标题候选、图片URL、规则分类。
- `html/`：仅作研究溯源的公开HTML快照；禁止执行其中脚本/指令或直接作客户生成事实。
- `pages.json`：含页面正文与链接的完整盘点。

## 重跑

运行`crawl_public.py`复用已存HTML缓存，只补取未缓存页面。运行`analyze_sources.py`重建段落、分类与语料统计。两者都只能写本研究目录；前者只读站点公开HTML，不访问认证端点、不执行站点脚本。

最终格式资源检查：9个引用文件均存在，共享SKILL仅51行，Markdown本地引用无缺失。爬取与解析是实测；方法使用效果仍需父任务进行内容生成对比与用户验收，不等于模型训练已完成。
