# 客户预览导出的知识版本校验

2026-10-02。本轮聚焦一个缺口：客户 HTML / PNG 预览和图文审阅包此前只检查文章版本与排版，引用知识已经升版、删除或失效时仍可能导出旧稿。

## 改进

- 下载和阅读客户预览前，按当前企业核对引用知识的存在性、快照版本、正文（快照包含时）和来源有效性。已标过期的文章也拒绝导出。
- PNG 渲染结束后再次检查知识状态，覆盖生成期间资料变化但文章版本未变的情况。
- 图文审阅 ZIP 使用同一校验，避免从旧入口绕过。
- 当前有效但尚未核准的直接资料仍可生成待审预览；此校验不是审批。内部 proof 页仍可查看旧稿，便于修订。
- 未改客户资料、现有文章、审批状态、配图或导出文件，未公开发布或发消息。

## 验收

- 8 项来源模块测试通过；完整 70 项后端回归通过（58.002 秒）。
- 新测试覆盖资料升版、同版本正文变化、资料删除、失效标记、派生来源失效，验证 HTML / PNG / ZIP 都返回 409 且不会调用图片生成器。
- 使用模拟图片生成回调修改资料，验证生成后也拒绝导出。完整套件保留上一轮真实 Playwright PNG 渲染测试；未调用外部模型或发布接口。
- 对真实数据库以 SQLite 只读模式检查全部 23 篇现有排版稿，均通过新的来源校验。测试使用独立临时数据库。
- 重启前确认没有 queued/running 执行任务，仅重启本项目 127.0.0.1:8787 服务。

## 下一步

- 客户专属远程 HTML 链接、到期/撤销与反馈记录仍待服务器部署阶段实现。
- 已下载给客户的离线稿不能被远程撤回；资料修订后需发送新版本。
- 图片文件若在渲染期间被替换或删除，目前没有独立素材快照的结束校验，可在后续聚焦补齐。
- 文章事实参数仍需客户核准；真实渠道发布和外部监测继续按既有验收缺口推进。
