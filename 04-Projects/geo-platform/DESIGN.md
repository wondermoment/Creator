# 企业 GEO 应用：首版设计约定

2026-10-02。面向制造业 B2B 服务团队及企业审核人，桌面 Web 优先。

## 参考与边界

主参考：用户提供的 WorkFX 工作台、分组侧栏、品牌入口与预览截图；参照已完成的 `Research/Web/2026-10-02-WorkFX-framework-study.md`。保留品牌上下文、分组导航、右侧成品预览、绿色操作强调。

次参考：已研究的 Trendee 监测→行动逻辑，用于诊断建议进入内容任务；refero-design 的 craft-details 用于标签、焦点、错误提示、对话框和响应式布局。当前无 Refero MCP，不虚构在线参考研究。

| 决策 | 来源 | 规则 |
|---|---|---|
| 三分区侧栏，企业入口与账户入口固定 | 用户截图和确认 | 总览、操作中心、企业知识与资产 |
| 企业知识库独立，Skill 单独配置页 | 用户明确要求 | 公共模板只共享能力，项目专属覆盖不共享客户资料 |
| 预览后通过，再交付 | 用户要求 | 审批绑定版本与渠道；改稿撤销当前审批 |
| 白色工作区，深色监控大屏 | WorkFX + 用户大屏要求 | 工作界面重阅读，大屏突出数值与来源 |
| 墨绿主操作、细灰边线、8–16px 圆角 | WorkFX + craft | 红色仅错误/驳回，琥珀色待处理，不装饰性渐变 |
| 状态刷新真实数据库 | 用户要求 | 不以随机数模拟效果；示例项目与真实空项目清楚区分 |

## 实现顺序

新增项目主管的视觉设计沿用桌面 Google 蓝色主操作和严格网格。工作台新增统筹入口，全局右下角唤起非模态侧栏：对话 / 任务清单 / 智能体与 Soul。用户请求的 MUSE 式交互仅作为常驻协作方向参考，不宣称研究或复制其内部实现。内容专家移入内容创作下的内容中台，创作页只保留当前专家状态。客资中心以联系入口→评论咨询→跟进阶段分层，所有连接状态明确呈现。

用户后续确认：电脑端优先；德式信息可视化风格，Google 配色。最终覆盖早期墨绿方向：严格网格、4–5px 圆角、白底、精简边线；蓝 #4285F4 / 操作蓝 #1A73E8，红 #EA4335，黄 #FBBC05，绿 #34A853。状态颜色同时配文字；大屏深蓝灰背景，使用相同数据系列色。1400px 以上优先三分区桌面布局。

账号→企业空间→资料与模板→诊断证据→内容版本→预览审批→发布任务→人工回执→客资跟进→动态统计。各对象带 project_id，服务端校验成员和角色；不依赖前端筛选保障隔离。

## 首版接入边界

2026-10-02 迭代：用户要求内容排期可创建自动化任务；内容助手三步流程；企业知识库拆为品牌 IP 资产和品牌视觉与图库；品牌基因及百问百答保留为子栏目；“Skill 与提示词”改为“内容中台”；社区洞察位于内容创作下。参考用户提供的日历、关键词→意图→初稿、品牌基因、资产、智库问答截图。采用统一 Google 状态颜色和德式网格设计，不复制参考中的渐变与促销遮罩。
