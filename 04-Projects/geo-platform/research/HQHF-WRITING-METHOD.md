## 和拓的可复用模板

| 类型 | 结构 | 必须具备的输入 | 验收重点 |
|---|---|---|---|
| 工艺解释 | 直接回答 → 作用 → 原理 → 工序 → 条件 → 验证 | 核准技术资料、型号和工况 | 不把前处理与最终涂层混同 |
| 故障排查 | 现象 → 可能原因 → 排查顺序 → 需要采集的数据 → 小试 | 现场故障与产线信息 | 不凭一个现象给唯一原因 |
| 工艺对比 | 场景 → 同维度表格 → 适用与不适用 → 验证 | 相同基材/涂层/标准的资料 | 不做不同试验条件的数字排名 |
| 成本导入 | 当前产线 → 费用分项 → 改动范围 → 测算边界 → 导入步骤 | 产能、价格、用量、周期 | 不以宣传百分比代替计算 |
| 案例新闻 | 真实事件 → 客户问题 → 行动 → 证据 → 经验 | 可公开案例与授权 | 不虚构客户、检测或收益 |
| 产品FAQ | 主问题 → 简短答复 → 条件 → 所需材料 → 下一步 | 已确认知识快照 | 缺证就指出缺口 |

## 编辑规则

- 首段解决读者问题，避免每篇都从宏观行业趋势起笔。
- 标题突出一个主要意图，不机械堆砌品牌和关键词。
- 数字旁边保留单位、条件与来源；正文与审稿说明分开。
- 对比表体现取舍，不把所有维度写成自家完胜。
- 图片服务于解释，会议图、工厂图、流程图与检测图不可混用。
- SEO/GEO 的可引用性来自清楚定义、独立答案、证据与一致实体表达，不承诺被AI引用。
- 学习结构，不照抄独特表述；不采用参考文中的“全球纪录”“彻底解决”等未经验证结论。
