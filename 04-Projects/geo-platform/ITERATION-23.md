# 迭代 23 · 图文预览与审批绑定同一版本

2026-10-02。本轮聚焦客户实际看到的图文和提交审批的版本一致性。

## 缺陷与修复

此前图文稿异步请求不含版本参数，审核操作又从可更新的页面 state 取 revision。可能出现预览内容、侧栏版本和提交版本不一致。加载失败时审核按钮也没有等待完整图片。

- 打开预览即保存企业、文章 ID、revision 快照；提交、批准、退回与创建交付均取该快照，禁止从更新后的 state 偷换版本。
- 图文请求和独立预览链接携带 revision。服务端在企业鉴权后校验版本，不一致返回 409；成功响应返回版本头并禁止缓存。
- 前端核验版本响应头，等待全部配图解码完成，再启用审核与交付按钮。HTML 缺失、版本改变、图片失败均保持不可审批并提示重新打开。
- 关闭、重开预览或切换企业会使旧异步响应失效，旧响应不能给新预览开启审核按钮。
- 仍支持不指定 revision 的只读直接预览入口，用于旧链接兼容；前端所有本次审阅链接均使用固定版本。
