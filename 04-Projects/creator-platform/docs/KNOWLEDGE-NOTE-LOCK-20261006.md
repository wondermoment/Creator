# 本地笔记并发保存保护 · 2026-10-06

## 交付

手工知识点、旧阅读笔记入口和公开书籍 AI 回复此前各自读取 localStorage 数组再写回，两个页面同时操作可能覆盖对方的新笔记。现在三个入口统一经由同源 Web Locks 独占锁串行追加，获得锁后才读取最新数据；读取校验与写入之间无异步等待。没有迁移、清理或替换已有用户数据。

锁等待上限 5 秒，超时中止排队，不执行迟到写入；不支持 Web Locks 时明确暂停保存，不回退到无锁写入。适用支持 Web Locks 的浏览器及 localhost/HTTPS 安全上下文。AI 回复同一记录使用稳定 UUID 在锁内去重，成功写入后才标记已保存。保存中显示状态，失败恢复按钮；切换书籍或开始下一次回复后，迟到保存结果不会重绘新窗口/新回复。

前端版本 `book-reader.js?v=note-lock-27`。**已打开的旧标签页需要刷新**；旧代码、开发者工具或其他不使用此锁的写入方不受该保护约束。锁不会让其他标签页的列表自动刷新。
