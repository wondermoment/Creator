# 攻略咨询上下文修复

## 问题与改动
旅行详情的咨询按钮曾使用乌布/酒店内部编号等非目录名称，openServiceChat 按名称匹配导致目录未命中。即使命中，也只提供旧的简短目录字段，未提供新增详细攻略。

现在 travelGuideSubject 优先获取当前目的地或酒店完整目录名称；客服上下文包含当前攻略的摘要、住宿、交通、饮食、预算核对与每日安排。无来源的编辑路线明确标为当地最新资料待核验；全部行程明确非已确认套餐、无实时房态团期。不再按字符截断 JSON。
