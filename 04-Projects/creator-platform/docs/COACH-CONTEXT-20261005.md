# 长对话早期限制保留 · 2026-10-05

## 问题与修复

前端原来只发送最近8条消息（有任务上下文）或10条消息（无任务上下文），即约4–5轮。更早的用户原话，包括过敏、用药和偏好，不再进入模型。后端还会把已校验的12条历史再次截成10条。

现在将最近窗口之外的用户原话按时间顺序放入 `earlier_user_messages`，本轮问题与最近历史照常发送。后端将早期原话作为用户资料传入，不升级为系统指令；提示后来明确更新的信息优先、冲突先确认，不把旧症状自动当作当前急症。后端保留全部通过校验的近期历史，不再二次静默截断。

原话最多40条、每条2000字符、合计16000字符，前后端均限制。超限会保留当前草稿并提示重新开启对话、重新说明目标和安全限制，不悄悄裁剪。没有提取或推断健康档案，没有增加持久存储，关闭并重开仍是新会话；较早助手回答不保留到模型上下文，因此不能声称完整长期记忆。

返回 `context_version: 1` 和 `policy_version: 2026-10-05-context`。当请求包含早期原话而旧后台没有确认支持时，前端不采用其回复，保留问题、提示后台尚未启用该能力。升级前短对话继续兼容；长对话会受到此保护性限制。缓存版本 `coach-chat.js?v=context-11`。
