# 书籍回答收藏回执与等待恢复 · 2026-10-06

## 问题与修改

代码审查发现原收藏事件只等待post返回，不校验saved回执；请求不结束时按钮一直禁用。重复事件没有消息级保护；保存完成时无条件paint会覆盖正在显示的新回答进度；旧窗口失败也未检查active。此次针对该流程修复，不重跑图像或全量模型案例。

新增readingSave：30秒截止、AbortSignal传给post、严格要求saved===true后才采用确认，结束清理计时器。超时/无效回执提示重新打开书籍或刷新知识库核对，未声称服务端一定未保存，也不会自动重试。消息ID级Set去重；已保存项不再重复提交。聊天忙时拒绝新收藏请求；若收藏提交后又开始了新回答，成功只更新内存中的saved标记，不重绘流式正文，待回答完成时正常显示已收藏。旧窗口失败不改新窗口或弹出成功提示。

## 验证

扩展tests/book-reader-async.cjs，合成传输覆盖：成功确认、saved:false、永不结束请求的30秒截止/Abort、迟到成功不冒充已确认、重复事件仅一次请求、跨书失败不影响新草稿、保存完成不改写新问题等待内容。其他历史/来源/长对话/超时恢复断言保留。

backend/test_book_evidence.py新增临时SQLite测试：同一回答收藏两次返回saved:true且不重复新增记录，跨书编号及用户消息均404，原内容不变。只在临时目录运行，不修改现有用户记录。

4套前端检查（book-reader-async、book-upload-async、book-public-sources、modal-stream-replace）、JS语法、6项后端证据/收藏检查全部通过，详见BOOK-SAVE-RECOVERY-CHECKS-20261006.json。

运行服务只读GET确认book-reader save-receipt-24及脚本字节与磁盘一致，无后台重启。后台代码未改，最近交接PID76932。

## 限制

本轮为合成DOM/传输与临时数据库验证，没有真实浏览器收藏写入，也没有真实模型调用。超时仍可能已在服务端收藏；提示核对，不提供跨设备回执保障。公开主题问答无持久message id时仍没有该收藏按钮，不能把本轮称为所有AI回答均可收藏。既有手工摘录入口仍可记录文字，但完整公共问答持久收藏属于单独待办。
