# 书籍取消流程原生浏览器验证 · 2026-10-07

## 本轮结果

补齐前几轮只有合成DOM/传输验证的浏览器层证据。独立 headless Edge Chromium 154.0.4258.53 中，16种场景全部通过：历史读取、资料状态、手动重新加载、上传等待响应头、上传回执读取、上传后状态、原文问答等待响应头、原文问答回执读取，各自关闭或替换窗口。

实际浏览器 AbortSignal 触发且原生 fetch 或 response.json 拒绝，页面操作结束等待，不依赖等待测试服务器返回。取消后重新打开另一书籍并发送合成问题，16次均成功展示合成答复并恢复发送按钮。取消历史读取不再触发该书资料查询；取消上传/上传回执不再追加后续资料状态请求。无未处理页面错误。

没有发现需继续修改产品代码的问题，因此本轮仅增加可重复测试与证据，不重跑既有模型样本或修改配图。

## 方法与证据

- 脚本：`tests/book-cancel-browser.py`，使用 webapp-testing 技能工作流。
- 结果：`BOOK-CANCEL-BROWSER-20261007.json`，逐例记录浏览器中止/拒绝、合成HTTP请求路径、源码SHA及浏览器版本。
- 运行静态核对：`BOOK-CANCEL-BROWSER-STATIC-20261007.json`，首次只读GET失败：127.0.0.1:8765拒绝连接。确认无监听/Python进程后恢复本地服务PID14888，再次GET核对5个被测文件SHA均一致；初次失败保留在证据中。

Python临时HTTP服务仅绑定127.0.0.1随机端口，不使用8765项目后台。服务返回合成历史、资料及答复，可在响应头或正文阶段暂停并由测试释放。上传仅使用内存合成TXT，请求内容读取后丢弃，不保存文件/数据库。测试浏览器仅允许访问此临时源，使用非持久独立上下文，不访问已有用户配置/存储。结束后上下文、浏览器与临时HTTP服务均关闭。

页面为合成外壳，运行真实book-reader、coach-chat、chat-format、request-errors以及从app原样提取的showForm/api/post等函数。浏览器的dialog关闭事件、fetch、AbortController、FormData及response.json为原生实现。手动重新加载在初次正常加载后按钮会隐藏，因此该场景直接调用实际onclick；其他上传/发送/关闭/切换通过DOM按钮操作。未加载chat-stream，本轮针对近期修改的同步原文与读取/上传路径。

## 明确限制

这不是完整产品/实际后台联合验收：没有真实模型推理、PDF解析、索引替换、数据库历史写入或实际用户资料。未测生产取消时延、云端算力停止、服务端任务回收或多实例资源。

测试特意在浏览器取消完成时断言服务端响应仍处于未释放状态，随后才放行。因此浏览器中止绝不能等同后台处理已中止或事务已回滚。原文问答/上传重开后核对历史或资料的提示仍需保留。实际后台断连处理、资源释放和完整联合验证仍在上线清单中。

本轮曾发现本机服务停止，依据既有重启授权恢复为PID14888，仅绑定127.0.0.1。启动前只读核对现有表/初始化种子标识并记录数据库摘要，启动后数据库文件SHA完全一致，首页及OpenAPI返回200，见LOCAL-RECOVERY-20261007.json。未重置数据或读取输出个人记录。无运行后台业务写请求、用户记录变更、真实模型调用、生图、API Key、支付、对外部署或外发消息。原始四姿势、既有插画和真实模型样本不重复。权限/隐私、受控备份导入、跨设备、专业签核、商户/材料授权与响应时延等门槛不变。
