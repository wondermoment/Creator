# 原文上传浏览器取消补齐 · 2026-10-07

## 修复

此前关闭或替换书籍窗口只隔离迟到 UI，上传传输、回执 JSON 读取和上传成功后的资料状态查询仍会继续等待。现在上传操作注册 close/formreplace 取消监听，readingUpload 和后续 readingLoad 接受外部 AbortSignal；取消会中止各自浏览器请求并独立结束等待，即使传输模拟实现不响应 AbortSignal 也不会卡住调用方。

上传回执到达前后均检查取消状态，迟到响应不再触发后续状态查询；处于状态核对阶段的请求也会中止。完成/失败/取消均清理监听和计时器。取消发生在旧 DOM 尚未替换时也不重绘旧错误或控件。预先取消的信号不会发送请求。

资料管理入口补充说明：关闭窗口只停止本页等待，后台可能继续解析；重新上传前先核对资料状态。保留原有上传120秒截止、读取15秒截止和未知上传结果的核对提示。启动时的历史/状态读取未在本轮接入关闭取消，仍由原有截止与旧结果隔离保护。

版本：`book-reader.js?v=upload-cancel-31`。没有后端修改或重启。
