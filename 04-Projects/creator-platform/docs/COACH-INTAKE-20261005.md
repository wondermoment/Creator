# 教练渐进询问与安全分流验证 · 2026-10-05

## 交付

此前真实模型对“帮我改良一道家常菜”一次询问菜名、人数、做法、偏好、健康限制、期限，增加了开始对话的负担。共享教练规则现要求先回应问题、复用已知信息，每轮只追问一个必要缺项，不在一个问号下捆绑多项；普通问答不强制询问期限。菜谱教练缺少菜名时先问菜名；信息足够后给用量、步骤、熟度与搭配。

个体化建议仍需相关安全条件，不把未知过敏或病史当作没有；当前急症优先求助。前端导出的 Skill 与后端运行说明同步；policy_version 为 `2026-10-05-intake`，前端缓存版本同步更新。
