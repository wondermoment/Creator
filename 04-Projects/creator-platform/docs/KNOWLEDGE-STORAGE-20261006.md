# 本地知识库读取异常保护 · 2026-10-06

## 问题与修复

此前 `readerNotes()` 通过通用存储函数读取 `wld-reading-notes`。读取被拒绝、JSON 损坏或结构不正确时，通用函数返回空数组；随后保存新笔记可能把原内容当作空列表覆盖。

现在只有存储键不存在才视为空列表。读取异常、解析失败或笔记结构不符合要求时，明确显示错误并暂停保存。手工摘录和公开书籍 AI 回复保存均先执行同一读取校验，因此不会在这些错误状态下写回存储。知识库页面显示“无法确认是否为空”的错误状态，不把故障展示为空列表。没有执行自动修复、删除或迁移。

记录校验覆盖数组、记录对象、已有文本字段类型、摘录/笔记内容及可选参考来源。合法旧记录及未知字段继续保留，避免不必要的数据迁移。前端版本为 `book-reader.js?v=storage-guard-26`。

## 验证

完整输出见 `KNOWLEDGE-STORAGE-CHECKS-20261006.json`。7 套前端检查与 JS 语法检查全部通过：knowledge-storage-integrity、knowledge-notes、knowledge-load、book-reader-async、book-public-sources、book-upload-async、modal-stream-replace。

新增测试全部使用合成 localStorage：空字符串、损坏 JSON、null、对象代替数组、异常记录/字段/来源及访问被拒绝时，两类保存均被阻止，写入次数为零，原始字符串保持不变。还检查故障提示、访问恢复后保存、合法旧记录及未知字段保留。

运行服务只读 GET 已确认首页使用新版本，静态脚本与本地文件字节一致。本轮未重启服务，未读取或修改真实用户 localStorage，未发送运行写请求、调用真实模型、生图、付费 API、外部部署、消息或支付。

## 局限与待办

这是合成故障回归，不是真实浏览器故障注入或知识库全链路验收。没有测试或修复跨标签页同时写入导致的覆盖竞争；备份、导出/恢复、跨设备同步、正式权限和隐私管理仍未完成。损坏数据保留原状，不能把暂停保存称为数据恢复成功。既有模型速度、完整 PDF Skill、医学签核及其他上线门槛仍见 RELEASE-BLOCKERS.md。
