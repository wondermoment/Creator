# 商城商品编号输入与输出边界

2026-10-06。核对最新交接后审查商品上架路径，发现具体缺陷：保存接口只检查 custom- 前缀与总长度，允许引号、HTML片段、空白和URL分隔符；商品工作台/详情将编号直接写入属性，构成存储型HTML/事件注入风险。现有本机访问限制不能代替输出转义。

## 修复

- 保存接口限定 custom- 后1–73个ASCII字母、数字、下划线或连字符，首字符字母或数字，总长最多80；正常后台UUID与既有测试短编号兼容。
- 工作台编辑/上传/预览、详情购买按钮转义编号属性；详情链接与保存/上传请求编码路径片段。图片URL原有编码保留。对于旧异常编号，前端输出也不再直接拼入属性。
- product-editor 静态版本更新为 id-escape-3。没有迁移、清洗或删除已有商品。
