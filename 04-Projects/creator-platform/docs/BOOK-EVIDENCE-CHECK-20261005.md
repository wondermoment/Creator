# 书籍问答异常引用与历史恢复

日期：2026-10-05。本轮检查智能体回答消费流程，不重复已完成角色图和12项检测图。

## 缺陷与修改

原reading-send先history.push，再paint。若sources非数组、元素为空或必要字段缺失，paint可能抛异常；已添加的坏记录留在内存，后续重试和主题问答历史构造继续受影响。初始历史同样直接赋值并置historyLoaded，导致格式错误后重新加载可能不再重新读取历史。

新增readingSources/readingMessage/readingHistory/readingReply：在提交内存历史前校验字符串回复、user/assistant角色、引用数组及ref/location/text，document可选字符串，id可选非空字符串。saved接受实际SQLite的0/1及布尔值并规范化，兼容未收藏/已收藏历史。缺省sources保持为空数组，不捏造来源。

整个历史数组验证成功后才赋值和标记加载完成；失败停用发送并显示重新加载。回复异常保留问题和此前有效对话，不追加半个回合、不自动重试、不清空草稿。原文模式继续提醒重开核对服务端历史；前端未显示不代表服务端没保存。

范围只为结构校验，不判断引用是否真实、论文结论是否准确，也不把合法sources视为医学审核通过。未改服务器存储或删除任何坏历史；若服务器持续返回坏记录，会保持不可发送并提示核对。
