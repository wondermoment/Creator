# 聊天无限等待修复 · 2026-10-05

本轮从最新交接的约135秒模型延迟出发检查异常恢复，发现frontend/coach-chat.js此前只在20秒显示慢提示，没有等待上限；fetch永久不返回会让输入与发送按钮一直禁用。

改动：coachRequest以270秒为本页等待上限（长于当前后端240秒生成超时），Promise.race确保挂起传输也能结束UI等待；AbortController中止浏览器请求，post第三可选参数将signal传给fetch。其他POST调用不变。
