# 书籍公开参考层与连续追问验证

日期：2026-10-06，上海时间。

## 交付

56本书均有独立的主题框架、阅读价值、批判性阅读边界和来源映射。35本有对应公开图书介绍（33本微信读书、2本Open Library原版书目），21本只有相关主题参考，不冒充已读取原书。另配16条机构公开科普及5条论文摘要，总56条去重来源。逐本清单见BOOK-PUBLIC-COVERAGE-20261006.md。

资料来自上一轮实际取得的output/book-public-weread.json、book-public-authorities.json、book-public-papers.json及Open Library候选，经选择和中文转述形成backend/app/book_public_knowledge.json。Google Books限流、无关Bing结果、404页面、错误版本/重复论文/不相关论文未采用。没有复制付费全文、绕过付费墙、使用付费API Key或宣称实时全网检索。

公开资料独立于用户上传库。研究问答请求用book_id在服务器选取当前书的资料包，内容作为user参考数据传入；系统约束区分简介、主题、一般知识和科学证据。每次只附当前书的少量资料，不将56本全量传入。GET /api/books/{book}/knowledge提供只读检查入口，普通及流式回复均返回本次提供的参考资料、版本和依据层级。

前端回复下方可展开来源介绍、核对日期及HTTPS链接；文本转义，拒绝非HTTPS和携带凭据的URL。用户上传原文后仍优先走/books/{id}/chat原文检索；公共层不修改已有PDF、聊天记录、摘录或数据库。公共主题问答仍只有当前窗口内历史，刷新不保留，未宣称长期记忆。

《酶学方法》图示分册指向基因编辑，已按DNA/合成生物学方向提供主题参考，不泛化为普通酶纯化书摘要。尚未确认的作者、版本、原文需后续PDF核对。当前层不是萃取全文Skill；未来需从有权使用的PDF建立可追溯的章节/页码证据再替换。

## 失败与修复

首次3个HTTP请求受测试进程环境代理影响返回502，未进入应用日志；测试客户端设置trust_env=False仅直连loopback后解决。失败记录保留。

首个成功回复后，紧接着2个请求被单槽误拒为忙碌。发现generate_stream先yield done后才清理子进程并释放槽；UI据done允许追问早于后台完成。现延迟done至清理和释放完成，正文delta仍实时转发。新增测试证明看到done时清理已完成且槽可重新取得。随后NOMA和第二大脑连续HTTP请求均成功，未插入人为延时或取消并发保护。所有失败记录保留，不能称首次全通过。
