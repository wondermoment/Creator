# 书籍上传等待与结果核对

日期：2026-10-05。上一轮已完成历史/状态GET等待和本地求助，本轮处理仍无上限的原文上传，未重复生成小乔图片。

## 改动

frontend/book-reader.js 新增 readingUpload，覆盖 fetch 与 response.json 的120秒等待上限（Promise.race + AbortController）。浏览器中断不代表取消服务端解析或撤销资料替换，界面明确区分服务端确认成功与上传结果未确认。

上传期间禁用发送、文件选择与重复上传；原文状态刷新不能与上传并行。前置拒绝无文件、不支持的扩展名、空文件和超过10MB文件。接口成功还要求 ready=true 且 chunks为正整数。成功后进行已有15秒限制的状态读取；成功上传但状态读取失败显示独立提示，不误报上传本身失败。

网络/解析/超时等失败不自动重传，也不自动用旧资料状态掩盖结果未知；显示“重新加载”让用户核对当前文件名称。所选文件和问题草稿保留。手动状态重读后仍保留上传结果未确认提示，并提醒读到旧资料不代表后台停止。该提示不能证明后台任务已经结束。迟到成功/失败不会触发额外状态请求或覆盖另一本书的窗口。

版本：book-reader.js?v=upload-wait-10。无后端修改或重启。

## 局限与上线条件
