# 通用保存表单异步隔离 · 2026-10-04

实际问题：showForm 使用共享 modal/form/submit 元素。关闭旧表单后打开新表单，旧保存成功可能关闭新窗口；旧失败或 finally 可能写入新错误区域、启用新提交按钮。

修复：每次打开生成递增窗口编号，提交与回调检查编号及打开状态，旧请求不再修改新窗口。当前窗口失败仍显示错误并恢复按钮，不清空表单。已提交服务器的保存不会因为关闭窗口自动取消，不能保证其未执行。

验证：tests/form-async.cjs 用延迟Promise模拟旧成功、旧失败和当前失败，三场景通过；已有阅读窗口三场景及六组请求错误测试全部通过，app.js语法检查通过。无真实后端提交、模型调用或用户数据修改。不是实际浏览器验收。
前端版本已更新；后端此前修复仍待授权重启，未再次尝试。
