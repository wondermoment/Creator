# 原文版本变化时拒绝旧答复提交 · 2026-10-07

## 交付

问答此前只校验历史是否变化，没有检查模型生成期间上传的原文是否已替换。本轮读取原文时同时记录该份原始字节的SHA256，答复提交前在SQLite写事务中核对当前原文。原文变化、删除或损坏均409拒绝本轮提交，提示重新打开核对；不会用旧摘录答复新增本轮历史。

上传原文的原子文件替换也参与同一个memory.db写锁，避免采用新版逻辑的上传在问答版本核对与历史插入之间替换文件。解析和暂存文件准备仍在锁外。没有数据库结构迁移，不改写既有原文或历史。同名文件、同样段落编号但正文不同也能识别；完全相同字节视为同一内容，其他书原文变化不影响本书。
