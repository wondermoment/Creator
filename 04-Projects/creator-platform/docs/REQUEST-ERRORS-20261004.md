# 前台请求错误提示 · 2026-10-04

发现：统一API仅拼接后端校验msg，常见错误显示英文且缺字段名；书籍上传直接将detail数组转成Error，可能显示[object Object]。
修复：增加共用错误格式化函数，将常见必填、字符长度、数字、选项错误转换为中文，附已知字段名称，最多展示三项且去重；不拼接校验input或ctx原始对象。保留后端已有中文业务错误，未知错误使用可理解提示。统一API对网络中断明确提示检查服务、先确认上次操作结果，避免承诺写入必然失败。书籍上传复用相同函数。
验证：六组Node断言通过，覆盖字段/数字/业务错误/私密input不显示/503/中文校验；app.js语法检查通过，书籍窗口异步回归三场景通过。无需真实模型或现有用户数据。未做浏览器端到端验收。
运行状态：前端增加版本参数，刷新可加载；此前后台修复仍未重启验证。没有对外部署、真实支付或发送消息。
