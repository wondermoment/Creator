# 公开书籍问答记入知识库 · 2026-10-06

上轮发现公开资料主题回复无服务端message id，因而没有原文模式的收藏按钮。本轮补充用户明确点击后保存在当前浏览器的记录路径，复用既有wld-reading-notes知识库，不冒充服务端或跨设备收藏。

## 用户流程

完整回复通过readingReply校验并进入历史后，显示“记入长寿知识库 · 仅当前浏览器”；生成中的临时正文没有按钮。点击保存书籍、用户问题、完整回答、已提供参考资料与时间；存储成功后显示“已记入本机知识库”。当前正在回答时提示先等待，以免误存不完整回复。

在“我的 → 知识库 → 我的摘录与笔记”呈现该记录，明确“AI公开资料交流 · 非原书摘录 · 未经专业复核”。回答分段/重点加粗，参考资料显示为本次提供的资料，不宣称逐条支持全部生成断言。原手工摘录与服务端原文回答收藏路径保持原有存放位置。

本地UUID对同一回复点击去重；保存前验证来源结构及HTTPS链接，写入使用新数组，不先修改已读记录。存储受限/容量不足会显示未确认保存、保留回复并允许重试；不会自动外发或删除旧笔记。页面刷新后不同对话中生成的相同文字不是全局去重对象。

## 验证

6套Node检查通过：knowledge-notes、book-reader-async、book-public-sources、book-upload-async、modal-stream-replace、reading-format，修改JS语法通过。新增合成用例覆盖按钮只出现在完整回复、问题/来源传递、保存后状态、无服务端POST、重复保存不增条、存储抛错不标成功、重试、旧笔记保留、HTML转义及危险来源拒绝。详细输出BOOK-PUBLIC-NOTES-CHECKS-20261006.json。

运行仅GET核对首页book-reader local-knowledge-25与脚本字节一致，无后台重启。没有在真实浏览器写入测试笔记，没有修改用户已有数据，没有新模型/生图/API Key/部署/支付或消息。

## 局限

这是当前浏览器本地保存，不支持跨设备同步，也不是服务端公开聊天历史持久化。清理浏览器数据会丢失本地笔记，隐私删除/导出与多用户隔离仍属上线条件。未做真实浏览器保存端到端验证；合成测试不等于医学或资料专业签核。来源公开不代表允许任意商业转载，也不代表已读原书全文。

上轮“公开主题回复没有直接记入入口”在本地知识库路径关闭，服务端持久收藏与跨设备功能仍未实现。已完成图像、65次既有真实模型样本不重复。
