# 检测咨询价格上下文 · 2026-10-04

发现：前台价格模式pending时隐藏截图金额，但新智能客服把整个检测对象JSON（含sourcePrice）发给模型。模型可能误把未确定口径的截图价当售价。

修复：检测上下文改为明确字段；pending/未知模式或无效金额不传数值与sourcePrice，只传价格待核实、不能推算折扣，并注明购买和机构预约未开通。已确认的original/discounted模式使用与页面一致的原价/五折价映射。全局testingPriceMode仍pending，没有推断用户未回答的价格口径。

验证：tests/service-chat.cjs通过既有三类入口、三种未确认模式数值隔离、两种明确模式映射及无效数字保护。JS语法通过。合成数据；没有模型调用或真实价格/订单修改。此验证只证明发送上下文，不证明模型绝不会自行猜价；上线仍须真实回复评估、商户与价格确认。
