# 书籍推荐问题一键发送 · 2026-10-06

用户要求三个推荐问题点击立即发出，并继续解决慢回复。book-reader.js将推荐问题从document级填草稿改为当前阅读窗口内部事件：单击调用同一send handler，马上显示用户问题、清空输入并展示真实等待时间；busy/disabled/active统一阻止重复请求和未加载时发送，失败恢复问题。已上传原文仍走原文检索接口，没有改走通用问答。

无原文推荐问题请求额外说明首轮120—180字、核心结论及三个简短要点，保留原文未核验/证据与安全边界；用户手动提问仍使用原规则。不是预生成答案或假流式输出。前端版本one-click-17，无后台变更/重启。

回归：book-reader-async新增两路推荐问题点击、加载中不发送、双击去重、立即清空/上屏、失败恢复；书籍异步、上传异步、安全排版、56本导读覆盖及JS语法通过。
